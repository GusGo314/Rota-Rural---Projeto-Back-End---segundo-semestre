# ROTA RURAL

`Analise e Desenvolvimento de Sistemas`

`Projeto: Desenvolvimento de uma Aplicação Interativa`

`EIXO 2`

O Rota Rural é uma plataforma digital criada para aproximar produtores rurais e compradores, facilitando a divulgação e comercialização de produtos agrícolas. O sistema permite cadastrar produtores e compradores, validar documentos, organizar produtos por microrregiões, realizar buscas, gerenciar pedidos e programar entregas, tornando o processo de compra e venda mais simples, seguro e organizado.
